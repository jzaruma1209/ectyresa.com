## Propósito de esta sección

Antes de tocar la API (backend `apiectyre`), el objetivo era: **verificar que el
frontend (`ectyrepage`) esté sano, limpiar la raíz del repo, y sentar una base
de documentación confiable** — para que cuando se modifique la API, no haya
errores por trabajar sobre información desactualizada.

Se decidió explícitamente **NO mezclar frontend y backend** en esta sesión:
son repos separados, se trabajan por separado, aunque en algún punto deban
funcionar juntos.

- **No se terminó de diagnosticar la causa exacta** — se le pidió al usuario

  1. El cuerpo exacto de la respuesta 404 (Network tab → Response) — el

     revelaría si el proxy está mandando la URL correcta.
  2. `curl http://localhost:8080/api/v1/carrito` directo, sin pasar por Vite.
  3. Reiniciar el backend local por si está corriendo una versión vieja del
     código (antes de que existiera `carrito.router.js`).
