---
description: Pasos para crear un nuevo componente base de React
---

Al crear un nuevo componente en este proyecto, sigue estos pasos:

1. Dirígete a la carpeta `src/components`.
2. Crea un nuevo archivo con extensión `.jsx` (ej. `Boton.jsx`).
3. Define el componente como una función exportada por defecto.
4. Recuerda agregar los estilos utilizando clases de Tailwind CSS.
5. (Opcional) Si el componente es complejo, crea una subcarpeta con el nombre del componente que contenga el `index.jsx` y otros recursos asociados.
